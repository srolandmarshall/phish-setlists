🎸 Inphinite Features

Complete Feature List

✨ Recent Additions (October 2025)

  • NEW Interactive Track Tooltips - Click any song to see performance details from Phish.in (date, venue, jamchart notes, teases, likes)
  • NEW Mobile-Optimized UI - Fully responsive design with touch-friendly tooltips and collapsible context
  • NEW Phish.in Show Links - Direct links to full shows from tooltips
  • Jamminess Control - Dial up or down jam intensity (0.0 = tight, 1.0 = extended jams)
  • Dynamic Set Lengths - Realistic duration based on jam intensity with multi-percentile system

🎯 Core Features

  • ML-Enhanced Generation - Historical placement probabilities and transition patterns
  • Weighted Set Closers - Songs selected based on historical ending probability
  • Authentic Track Versions - Actual set-ending recordings from Phish.in
  • Smart Frequency Caps - Prevents rare songs from appearing too often
  • Era-Aware Selection - Filter by 1.0, 2.0, 3.0, or 4.0 eras
  • HTML Playlists - Interactive setlists with embedded audio player
  • M3U Export - Download playlists for external players
  • 40+ Years of Data - Powered by comprehensive Phish.in archive

🔧 Technical Features

  • FastAPI REST API - Full programmatic access
  • Local-First - Uses local Postgres database for speed
  • Constraint Solver - Duration targets with intelligent relaxation
  • Seed Control - Reproducible setlist generation
  • Multi-Percentile Duration - p30/p50/p70/p90 based on jam setting

⚠️ Known Issues

  • Opener selection can be improved
  • Hold Your Head Up selection may not match up with paired songs
  • Short songs appear overweighted as set closers
  • Alumni Blues > Jimmy Page is excluded because of wonkiness
  • Jamminess control is experimental – results may vary wildly!

📊 Data Attribution

All Phish show and setlist data is sourced from Phish.in, a comprehensive archive of Phish recordings and setlists. This project would not be possible without their incredible work maintaining this community resource. Phish.in data is provided under the MIT License.
